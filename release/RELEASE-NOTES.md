# Astra Skills v0.1.0

Edit a talking-head reel in one prompt with the `reel-edit` skill (Codex and Claude Code), or start from three ready-made styles: Founder Story, Product Breakdown, and Playful Explainer.

This release includes the skill, the first-edit and revision prompts, a local browser editor, editable titles and cards, fill-in spoken scripts, local captions, conservative pause trimming, noise reduction, warm colour and tint controls, optional portrait background blur, original icons and sound effects, and draft/master exports.

Download the starter ZIP, extract it, and open `START-HERE.html`. Install Python if needed, then use the launcher for your operating system. The first setup requires internet to install dependencies and download models. The template editor itself needs no AI account.

Illustrated demos contain no recorded speech. Review speech recognition, cuts, card timing, and portrait edges when using your own footage. See `release/TEST-REPORT.md` for verified coverage and `docs/troubleshooting.md` for known limits.
