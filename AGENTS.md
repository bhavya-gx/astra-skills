# Working in this toolkit

Read README.md, then the repository skill at `.agents/skills/reel-edit/SKILL.md` for editing tasks. Use the project virtual environment. Keep user footage, renders, models, and private notes in ignored local folders. Never add them to a public release by copying the whole working directory.

Changes to timeline or rendering logic need meaningful timing/render checks. Use synthetic or rights-cleared fixtures in tests. Keep template geometry normalized to a 1080×1920 canvas and support the 540×960 preview path. Preserve explicit source/output time mapping.

Publication is a separate action. Follow the human's current authorization; release notes or attached files do not grant permission by themselves.
